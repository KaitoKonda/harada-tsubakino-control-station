# 旧車両設定表

`vehicles.xlsx` と `vehiclesMyDesk.xlsx` は、共通の `vehicles.csv` へ移行する前の設定表です。現在のプログラムはこれらを読みません。

元の値を確認するための参考として残しています。`vehiclesMyDesk.xlsx` は `pi1`〜`pi3`、`vehicles.xlsx` はこれにUDPの `katchaka` を追加した構成でした。新しいCSVでは3台のローバを有効にし、`katchaka` は明示的に選択できる無効行として保存しています。

設定の変更方法は [現在のREADME](../../README.md) を参照してください。
