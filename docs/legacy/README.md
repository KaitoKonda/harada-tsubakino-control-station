# 移行前の車両設定表

`vehicles.xlsx` と `vehiclesMyDesk.xlsx` は、旧版の文書フォルダーから参照用に複製したものです。**現行プログラムはこれらを読み込みません。** 現行の車両定義は [`+vehicleProfiles/`](../../+vehicleProfiles/) と [`+shared/experimentConfig.m`](../../+shared/experimentConfig.m) で管理します。

旧版のプログラム、CSV、元の文書と表は [`legacy/controlStationV1/`](../../legacy/controlStationV1/) に保存しています。表の値を現行の接続先として使う前に、現地の車両・ネットワークで確認してください。
